Or use an API token / OAuth settings

Log in to iNaturalist, then open inaturalist.org/users/api_token and paste the token below. Tokens expire after 24 hours. It is stored only in this browser's localStorage.

Register an app at inaturalist.org/oauth/applications/new (not confidential) with redirect URI , then paste its Client ID.
